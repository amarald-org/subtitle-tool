**First launch**
- **macOS:** the app isn't notarized yet. Drag it to Applications, then right-click it and choose **Open** (or System Settings › Privacy & Security › Open Anyway).
- **Windows:** unzip, run `Subtitle Tool.exe`. SmartScreen may warn about an unknown publisher: **More info › Run anyway**.
- **Linux:** `chmod +x Subtitle-Tool-*.AppImage` and run it.

Whisper models for automatic subtitles download on first use (small: 480 MB).
